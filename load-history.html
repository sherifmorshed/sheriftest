Load the 2026 history

Writes the 116 days extracted from Ras Gara Test 2026.xlsx (8 April → 8 August 2026) into this project's rasGara collection. Run it once.

This is a development tool — do not deploy it. It is not part of the app and nothing in the app links to it. Delete it, and history-data.js, once the history is in.

What it will do

  • Sign in with your admin account.
  • Write one document per day, each carrying the 24 hourly readings.
  • Skip any day that already has readings, so it can never overwrite something entered in the app. Run it twice and the second run writes nothing.
  • Update the version stamp last, so other devices pick it all up at once.
